# Albion OS

### An experimental independent operating system project.

Albion OS is a lightweight, experimental operating system project with a graphical desktop environment, custom interface, built-in applications, and a focus on simplicity and customization.

The current development build provides a functional bootable ISO that can be tested in a virtual machine such as Oracle VM VirtualBox. Albion OS is still in early development and is not intended to be a production-ready operating system yet.

# Running Albion OS

## VirtualBox

Albion OS can be tested using Oracle VM VirtualBox.

### Steps

1. Obtain the Albion OS ISO from the project's release/download location.
2. Open **Oracle VM VirtualBox**.
3. Create a new virtual machine.
4. Select an appropriate operating-system type.
5. Allocate RAM and CPU resources appropriate for your system.
6. Attach the Albion OS ISO as the virtual optical disk.
7. Start the virtual machine.
8. Boot into Albion OS.

> Albion OS is currently intended primarily for virtual-machine testing. Hardware requirements are still being determined.
